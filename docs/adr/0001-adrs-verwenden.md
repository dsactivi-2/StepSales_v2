# ADR-0001: ADRs verwenden

- **Status:** Akzeptiert
- **Datum:** 2026-11-25

## Kontext

Architekturentscheidungen gingen bisher in Chats verloren. Mehrere Agents und Menschen arbeiten am Projekt.

## Entscheidung

Jede Architekturentscheidung wird als ADR in `docs/adr/NNNN-titel.md` nach der Vorlage `template.md` festgehalten. Status: Vorgeschlagen → Akzeptiert → (Ersetzt durch NNNN | Verworfen). Akzeptieren darf nur der Owner.

## Konsequenzen

Entscheidungen sind nachvollziehbar und prüfbar. Kleiner Mehraufwand pro Entscheidung.
