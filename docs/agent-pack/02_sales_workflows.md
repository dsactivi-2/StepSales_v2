# 02 — Sales Workflows

## Core Funnel

1. identify recent hiring activity
2. cold outreach call
3. establish relevance
4. permission to continue
5. qualify need and urgency
6. position the package
7. handle objections
8. close now or move to second step
9. send offer or payment link
10. follow up if needed
11. confirm payment
12. request fulfillment data

## Workflow A — Direct Close on First Call

- opener
- relevance hook
- discovery
- fit confirmation
- package recommendation
- objection handling
- close
- payment link
- post-sale request

## Workflow B — Close on Second Call

- opener
- discovery
- qualify
- offer / recap
- book second call
- second call close
- payment link
- post-sale request

## Workflow C — Offer Then Follow-up

- opener
- discovery
- buyer interested but not ready
- send offer
- reminder 1
- reminder 2
- payment link if accepted

## Workflow D — Inbound / Callback

- identify interest source
- answer core questions
- qualify
- recommend package
- close or move to next step

## Decision Points

At each conversation, determine:

- is this the right person?
- is there active hiring need?
- is timing current?
- is buyer open to additional distribution?
- is the barrier price, timing, trust, or authority?
- should we close, schedule, send material, or end politely?

## Minimum Next-Step Outcomes

Every call should end in exactly one of:

- closed
- second appointment booked
- offer promised
- material promised
- callback window agreed
- disqualified / no fit
- no interest / closed-lost
