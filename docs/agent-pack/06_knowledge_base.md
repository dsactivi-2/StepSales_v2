# 06 — Knowledge Base

## Purpose

The knowledge base should give the agent enough factual grounding to:

- explain the product clearly
- position packages correctly
- answer objections
- explain payment and next steps
- avoid hallucinating details

## Recommended Sections

### 1. Company and Product Overview

- what the company sells
- who it helps
- the value of multiposting
- typical buyer profiles

### 2. Package Catalog

For each package:
- package name
- included portals
- duration
- list price
- add-ons
- ideal customer profile
- when to recommend it

### 3. Portal and Reach Positioning

- why additional placement helps
- when multiposting is useful
- how to explain incremental reach
- what buyer pains it solves

### 4. Objection Handling Library

- “too expensive”
- “we already posted somewhere”
- “send me something”
- “not interested”
- “call later”
- “we already have a provider”
- “we need approval”

### 5. Discount Policy

- when discount is allowed
- max 10%
- how to frame it
- when not to use it

### 6. Offer and Payment FAQ

- how offers work
- what payment methods are supported
- what happens after payment
- what data is needed to launch

### 7. Post-Sale Fulfillment Checklist

- all required data for job ad publication
- expected turnaround
- who sends what

## Document Format Recommendation

Use short, structured docs:

- one package per document
- one objection family per document
- one payment/process document
- one fulfillment checklist document

This makes retrieval more reliable for voice agents.
