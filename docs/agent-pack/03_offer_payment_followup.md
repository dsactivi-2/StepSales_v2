# 03 — Offer, Payment, and Follow-up

## Offer Flow

If no immediate close:

1. summarize the need
2. recommend the package
3. confirm recipient email
4. send offer
5. confirm when the buyer will review it
6. set a clear follow-up point

## Follow-up Logic

### Follow-up 1

- send shortly after the first call
- recap value
- attach / link offer
- ask for simple confirmation or a short review slot

### Follow-up 2

- if no answer
- short reminder
- reference earlier discussion
- lower friction with direct reply options

### Follow-up 3

- if offer still open
- final concise nudge
- optionally propose brief second conversation

## Payment Flow

If buyer agrees:

1. confirm package
2. confirm final price
3. mention any approved discount explicitly
4. send payment link
5. clarify supported methods:
   - direct debit
   - credit card
   - bank transfer
6. confirm expected payment timing

## Post-Payment Flow

Immediately after payment:

1. send confirmation
2. send structured data request for fulfillment
3. request all information needed for job publication
4. confirm who will supply the job ad content

## Data Needed After Payment

- job title
- company name
- location
- employment type
- salary info if available
- job description
- requirements
- benefits
- target portals / package
- contact details for publication
- branding assets if relevant

## Second Call Use Cases

Use second call when:

- buyer needs approval
- buyer wants internal review
- buyer needs a more formal commercial conversation
- buyer is warm but not ready to decide live
