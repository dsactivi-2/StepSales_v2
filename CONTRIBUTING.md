# Mitarbeiten

Verbindliche Regeln stehen in [AGENTS.md](AGENTS.md). Kurzfassung:

1. Issue anlegen oder zuweisen lassen (Template wählen, Labels `stage:*`, `area:*`).
2. Branch `<type>/<issue-nr>-<kurz>` von `main`.
3. Conventional Commits.
4. PR mit ausgefülltem Template; `main` nur per PR, Merge durch den Owner.
5. Architekturänderung → ADR in `docs/adr/`.
6. Deploy, Workflow-Aktivierung, echte Anrufe, Stripe-Live nur nach „bestätige“ des Owners.
